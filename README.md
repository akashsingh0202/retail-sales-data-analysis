# Retail Sales Data Analysis

## Project Overview
An end-to-end Retail Sales Data Analysis project focused on understanding business performance, customer behavior, product performance, and sales trends using Python, SQL, and Power BI.

## Dataset
The project contains synthetic retail data covering 2023–2025.

- 100,000 Retail Transactions
- 12,000 Customers
- 650 Products
- 35 Stores
- Calendar Dataset

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- MySQL
- Power BI
- Git & GitHub

## Project Objectives
- Analyze overall sales and profit.
- Identify top-performing products and categories.
- Understand customer purchasing behavior.
- Analyze regional and store performance.
- Evaluate discounts and product returns.
- Build an interactive Power BI dashboard.

## Project Structure
- `dataset/` – Raw datasets
- `notebooks/` – Python analysis
- `visualizations/` – Charts and graphs
- `power-bi/` – Power BI dashboard
- `sql/` – SQL queries
- `reports/` – Business reports
